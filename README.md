# Cocoon Tales — Immersive Next.js Experience

This is the substantially redesigned Cocoon Tales experience: Next.js + React + TypeScript + Tailwind CSS + GSAP/ScrollTrigger + Lenis. It is intentionally different from the earlier PHP/editorial prototype and uses pinned scroll scenes, a drawn silk thread, horizontal archive, cinematic chapters, magnetic CTA and procedural texture.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

Recommended deployment: Vercel.

## Before launch
Replace the placeholder SVG artwork in `public/images/` with properly licensed Cocoon Tales photography. Configure an authenticated email/API service for enquiries rather than relying on a browser mailto link.
